# Калмыкия — навстречу простору

Адаптивный travel-сайт о республике Калмыкия: полноэкранная степь, белый заголовок снизу слева и тёмные редакционные разделы.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Откройте http://127.0.0.1:3000. Для производственной сборки:

```sh
npm run build
npm start
```

Проверки: `npm run format:check`, `npm run lint` и `npm run typecheck`.

Форматирование: `npm run format` запускает oxfmt с сортировкой импортов и Tailwind-классов. `npm run lint` использует oxlint, а `npm run lint:fix` применяет его автоматические исправления.

В настройках oxfmt указан файл стилей `src/app/globals.css`. Для `src/app/layout.tsx` разрешены стандартные экспорты Next.js `metadata` и `viewport`; остальные файлы используют общее правило `react/only-export-components`.

Все прямые зависимости закреплены на точных версиях. В `.npmrc` включён `save-exact`, чтобы новые зависимости также сохранялись без `^`.

## Что работает

- Навигация по разделам и мобильное меню.
- Описания мест в доступных диалогах Base UI, закрытие клавишей Escape.
- Четыре сезонных маршрута, управление вкладками с клавиатуры.
- Скачивание выбранного маршрута в UTF-8 TXT.
- Вопросы и ответы в аккордеоне.
- GSAP: появление заголовка, масштаб изображения, параллакс, раскрытие разделов, смена сезона и движение крупного названия в подвале.
- Системный `prefers-reduced-motion` и отдельный переключатель анимаций. Без JavaScript основное содержимое остаётся видимым.

## Структура

- `src/app/page.tsx` — серверная композиция страницы.
- `src/components/experience.tsx` — интерактивные компоненты Base UI.
- `src/components/motion-shell.tsx` — GSAP с `useGSAP`, локальной областью и очисткой анимаций.
- Стили компонентов задаются Tailwind-классами в `className`, включая адаптивность и состояния Base UI.
- `src/app/globals.css` — подключение Tailwind CSS 4, токены темы, базовые стили и глобальные настройки доступности.
- `src/lib/content.ts` — места, маршруты и ответы.
- `public/images` — оптимизированные WebP, используемые на сайте.

## Контент и изображения

Изображения созданы с помощью ИИ. Они не являются документальными фотографиями достопримечательностей. Это также указано в интерфейсе. Перед публичным туристическим запуском стоит заменить их проверенными фотографиями с согласованными правами и подтвердить актуальность сведений.

Справочные источники: [туристический портал Калмыкии](https://www.tourism-kalmykia.ru/), [Золотая обитель](https://khurul.ru/contacts), [заповедник «Чёрные земли»](https://zapovednik-chernyezemli.ru/).

Маршруты — идеи для самостоятельного планирования. Бронирование, платежи, сбор персональных данных и внешняя аналитика отсутствуют.

Перед публикацией задайте реальный адрес сайта в `NEXT_PUBLIC_SITE_URL` для Open Graph. Пример находится в `.env.example`. Сам сайт пока запущен только локально.
